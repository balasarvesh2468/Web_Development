Internet and Web

The Internet is a global network of connected computers.

The World Wide Web is a collection of pages and files that run on top of that network.

Internet

It is a global network of connected computers.

It transports data between devices using protocols, e.g. TCP/IP.

World Wide Web

A system of interlinked pages, documents, and media accessed via the internet.

Its components are:

  • URL
  • HTML
  • HTTP/HTTPS
  • Web Browser
