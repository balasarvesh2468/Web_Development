To know how the Web works, we must learn what's happening in the background.

Client and server

Computers connected to the internet are called Clients and Servers.

Our devices are Clients.
The computers of companies or website owners are Servers.

Other things we must know

Internet connection allows us to send and receive data on the internet.

TCP/IP are the protocols that are responsible for sending and receiving data. They also control how the data should travel.

DNS - When we type in an address in plain English, DNS looks up its name on its server to load that website, e.g. for google.com it finds the IP address of Google's server.
Since remembering such numbers is difficult, DNS gives a label (google.com) to the number.

HTTP/HTTPS is a protocol that defines a language for clients and servers to speak to each other.

Files A website is made up of many different files.
